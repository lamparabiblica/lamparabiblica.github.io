# Lámpara Bíblica

App para memorizar versículos de la Biblia (Reina-Valera 1960): tarjetas de repaso, práctica de llenar espacios, escribir completo y recitar, repetición espaciada, prueba de nivel inicial y panel de progreso por usuario.

Versión en línea: https://ecommsimone-lab.github.io/lampara/

Estado: prototipo. Las cuentas y el progreso se guardan en la nube (Supabase), con reglas para que cada usuario solo acceda a sus propios datos. `supabase.js` es la librería oficial @supabase/supabase-js 2.45.4.
